# 📚 Instrucciones Personalizadas - Arquitectura Empresarial

## Objetivo
Estandarizar la generación de resúmenes detallados de cada clase de Arquitectura Empresarial.

---

## 🎯 Proceso Estándar: Resumen Detallado de Clase

Cada vez que se solicite un **resumen detallado de lo que se vio en clase**, se debe seguir este flujo:

### Paso 1: Recopilar Materiales
- ✅ Identificar archivos de presentación (PPTX, PDF)
- ✅ Localizar imágenes de la clase
- ✅ Reunir resumen conceptual o notas de clase

### Paso 2: Procesar Presentación
- 🔄 Convertir PPTX a PDF (si aún no existe)
  - Comando: `soffice --headless --convert-to pdf --outdir . "archivo.pptx"`
- 📋 El PDF se genera en la misma carpeta

### Paso 3: Organizar Imágenes
- 🖼️ Renombrar imágenes con nombres descriptivos (en minúsculas-con-guiones)
  - Formato: `tema-subtema-ae.png` o `tema-descripcion.png`
  - Ejemplo: `tripode-normativo-ae.png`, `ceremonias-arquitectura-ae.png`
  - NO usar: `image-1.png`, `slide-1.png`, etc.

### Paso 4: Generar Documento Markdown
- 📄 Crear archivo: `CLASE-X-TITULO-TEMA.md` (reemplazar X con número)
- 📋 Estructura recomendada:
  1. Encabezado con metadata (Profesor, Fecha, Tema)
  2. Introducción con contexto
  3. Secciones temáticas numeradas (1, 2, 3, etc.)
  4. Tablas comparativas donde sea relevante
  5. Ejemplos prácticos y casos de uso
  6. Conclusiones finales
  7. Sección de recursos (referencias a PDF, imágenes)

### Paso 5: Validar Integridad
- ✅ Actualizar referencias de imágenes en el markdown
- ✅ Confirmar que todos los enlaces funcionan
- ✅ Verificar que los nombres de archivos coinciden

### Paso 6: Estructura Final
La carpeta de clase debe contener:
```
clase-X/
├── CLASE-X-TITULO-TEMA.md          ← Documento principal
├── PRESENTACION-NUMERO.pdf         ← Versión PDF
├── PRESENTACION-NUMERO.pptx        ← Original (opcional)
├── tema-subtema-ae.png             ← Imágenes descriptivas
└── otra-imagen-ae.png
```

---

## 📝 Convenciones de Nomenclatura

### Imágenes
- **Patrón:** `[tema]-[subtema]-ae.png` (minúsculas, guiones)
- **Ejemplos:**
  - `tripode-normativo-ae.png`
  - `ceremonias-arquitectura-ae.png`
  - `roles-gobernanza-ae.png`
  - `flujo-decisiones-ae.png`

### Documentos Markdown
- **Patrón:** `CLASE-[numero]-[TITULO]-[TEMA].md` (números romanos/arábigos)
- **Ejemplos:**
  - `CLASE-4-GOBERNANZA-AE.md`
  - `CLASE-5-MODELADO-EMPRESARIAL.md`

### Presentaciones
- **Patrón:** `PRESENTACION-NUMERO.pptx` o `PRESENTACION-NUMERO.pdf`
- **Ejemplos:**
  - `40096-S04-PRESENTACION.pptx`
  - `40096-S04-PRESENTACION.pdf`

---

## ✨ Checklist de Entrega

Antes de considerase completado un resumen detallado, verificar:

- [ ] PPTX convertido a PDF
- [ ] Todas las imágenes renombradas descriptivamente
- [ ] Documento markdown creado con estructura completa
- [ ] Referencias de imágenes actualizadas en markdown
- [ ] Archivo de recursos lista con PDF, imágenes, PPTX
- [ ] Nombres de archivos siguen convenciones
- [ ] Contenido incluye: principios, políticas, estándares, casos prácticos
- [ ] Conclusiones claramente articuladas

Este proceso se aplica automáticamente cuando se solicita:
- "Genera un resumen detallado de lo que se vio en clase"
- "Crea un documento markdown de la sesión"
- "Organiza los materiales de clase"
- Cualquier variación que implique creación de documentación completa de una sesión

---

## 📌 Notas Importantes

- La gobernanza de arquitectura tiene TRES niveles: Principios (estratégico), Políticas (táctico), Estándares (operativo)
- Incluir siempre ejemplos prácticos y casos de uso reales
- Las ceremonias son espacios estructurados, no reuniones informales
- Los roles deben tener responsabilidades explícitas
