## ¿De qué trata esta actividad?

Compara los modelos frontera de **Anthropic** y **OpenAI** usando el benchmark **SWE-bench Verified**: una prueba estándar que mide la capacidad de un modelo para resolver issues reales en repositorios de GitHub.

El objetivo es que puedas elegir el modelo más adecuado para tareas concretas de desarrollo de software.

## Benchmark principal

**SWE-bench Verified** — mide qué porcentaje de issues reales de GitHub resuelve un modelo de forma autónoma. Es el indicador más relevante para equipos de ingeniería de software.
