## 1. Resumen Ejecutivo

Entrar al retail canadiense (supermercados, tiendas de salud, marketplaces) es **viable pero no es fácil**. El mercado es relacional — los compradores reciben miles de pitches al año. Necesitas: producto diferenciado, documentación completa, broker o contactos, y paciencia.

**¿Por qué vale la pena para PureDose?**
- **Formato único** — sachets individuales no existen en retail canadiense
- **Tendencia eco** — consumidores buscan productos sin plástico
- **Hecho en Canadá** — ventaja local vs importados
- **Precio competitivo** — $0.42/dosis vs $0.49 de competidores premium
- **Tamaño compacto** — fáciles de almacenar y exhibir

## 2. El Proceso de Retail en Canadá

### 2.1 Flujo Completo

```
FASE 1: PREPARACIÓN (Mes 1–2)
──────────────────────────────
→ Obtener Safe Food for Canadians Licence
→ Obtener GS1 barcode
→ Diseñar label bilingüe (English + French)
→ Crear sales sheet + price list
→ Preparar muestras

FASE 2: CONTACTO (Mes 3–4)
──────────────────────────────
→ Identificar brokers en Ontario
→ Enviar cold outreach
→ Reuniones informativas
→ Negociar términos con broker

FASE 3: RETAIL (Mes 5–8)
──────────────────────────────
→ Broker presenta a compradores
→ Reuniones con compradores
→ Vendor setup (6–12 semanas)
→ Primera orden de compra

FASE 4: MONITOREO (Mes 9+)
──────────────────────────────
→ Medir velocity (units/store/week)
→ Soporte a tiendas
→ Re-orden o delisting
→ Expandir gradualmente
```

### 2.2 Timeline Realista

### 3.1 Comparativa de Canales

| Canal | Dificultad | Costo | Timeline | Control |
|---|---|---|---|---|
| **Broker** | Media | 3–10% comisión | 3–6 meses | Bajo |
| **Distribuidor** | Media | 25–35% margen | 3–6 meses | Bajo |
| **Directo a tienda** | Baja | $0 | 1–2 meses | Alto |
| **Directo a comprador** | Alta | $0 | 6–12 meses | Alto |
| **Trade shows** | Media | $500–$5,000 | 3–6 meses | Medio |

### 3.2 Opción Recomendada: Broker

Un **broker** es un agente de ventas que tiene relaciones con compradores de retail. Es la forma más efectiva de entrar al mercado canadiense.

**Ventajas:**
- Relaciones establecidas con compradores
- Conocimiento del mercado local
- Negociación experta
- Menor tiempo de entrada

**Desventajas:**
- Comisión del 3–10% sobre ventas
- Menor control sobre negociación
- Dependencia de un tercero

## 9. Consejos Clave para Retail Canadiense

### 9.1 Lo que Funciona

| Consejo | Detalle |
|---|---|
| **Persistir** | Los compradores reciben 100+ emails/semana |
| **Ser profesional** | Sales sheet, muestras, datos |
| **Diferenciarse** | Sachets individuales = único en el mercado |
| **Empezar pequeño** | Tiendas independientes primero |
| **Medir velocity** | Units/store/week es la métrica clave |
| **Relaciones** | El retail canadiense es relacional |
| **Made in Canada** | Ventaja local vs importados |

### 9.2 Lo que NO Hacer

| Error | Consecuencia |
|---|---|
| **Overexpandir** | Stock-outs = delisting |
| **No tener datos** | Compradores rechazan |
| **Precio alto** | No compites en estante |
| **No soporte** | Productos se quedan sin vender |
| **Contactar directo** | Difícil sin relaciones |
| **No diferenciarse** | "Me-too" products = rechazo |

### 9.3 Métricas Clave

| Métrica | Objetivo | Consecuencia si falla |
|---|---|---|
| **Velocity** | >2 units/store/week | Delisting |
| **Fill rate** | >95% | Pérdida de confianza |
| **Out-of-stock** | <5% | Delisting |
| **Re-orden** | Mensual | Expandir distribución |
| **Consumer feedback** | Positivo | Mantener listing |
