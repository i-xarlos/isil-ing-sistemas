# Especificaciones Envase Premium — Aluminio Reutilizable

**Estado:** Planificación Año 2 (diferenciador, NO para MVP)  
**SKU futuro:** Starter Kit Premium  
**Fecha:** 04/09/2026  

---

## 1. Resumen

El envase de aluminio es un **diferenciador estratégico para Año 2**, no un componente del MVP. PureDose lanza con contenedor reutilizable de plástico en el Starter Kit ($29.99). El envase premium se activará cuando el brand tenga tracción suficiente para justificar el costo adicional.

**Precio estimado Starter Kit Premium:** $39.99–$44.99 CAD

---

## 2. Especificaciones Técnicas

| Característica | Especificación |
|---|---|
| Material | Aluminio anodizado grado alimentario (Ali_1100 / Ali_3003) |
| Capacidad | 750 mL – 1 L |
| Peso | 150–230 g (según proveedor y especificación) |
| Diámetro | ~8.5 cm (compatible con sachets estándar) |
| Altura | ~12–14 cm |
| Tipo de cierre | Tapa rosca o tapa a presión con sello hermético |
| Acabado | Anodizado mate (color natural, negro, o verde eco) |
| Personalización | Grabado láser o serigrafía (mínimo 500 unidades) |
| Certificaciones | Food-grade FDA, Libre de BPA |

## 5. Criterios de Activación (Year 2)

El envase premium se activa **solo cuando se cumplan TODOS** estos umbrales:

| Criterio | Umbral | Estado actual |
|---|---|---|
| Clientes totales | 500+ | En progreso |
| Pedidos mensuales | 100+/mes | En progreso |
| Tasa de recompra | 30%+ | En progreso |
| NPS (Net Promoter Score) | 8+/10 | En progreso |

**Regla:** Si no se alcanzan estos números, se mantiene el contenedor de plástico.

---

## 6. Ventaja Competitiva del Envase Premium

| Aspecto | Contenedor plástico | Contenedor aluminio |
|---|---|---|
| Percepción | Estándar, funcional | Premium, duradero |
| Retención en cocina | Baja (se descarta) | Alta (se reutiliza años) |
| Impacto ambiental | Plástico reutilizable | Metal 100% reciclable |
| Diferenciación | Ninguna | **Único en la categoría** |
| Costo adicional | — | +$1.60 COGS |
| Aumento precio justificable | — | +$10–$15 CAD |

**Insight:** El aluminio no es solo un envase — es un **objeto de marca** que permanece visible en la cocina del cliente, reforzando el posicionamiento premium de PureDose.

## 8. Riesgos y Mitigaciones

| Riesgo | Probabilidad | Impacto | Mitigación |
|---|---|---|---|
| Precio alto rechazado | Media | Alto | Testear con encuesta antes de producir |
| Tiempo de entrega largo | Alta | Medio | Pedir muestras 3 meses antes |
| MOQ alto para piloto | Media | Medio | Buscar proveedores con MOQ ≤ 500 |
| Daño en tránsito internacional | Baja | Alto | Empaque reforzado + seguro |
| Competidores copian formato | Media | Bajo | Primera marca en ofrecerlo, construir lealtad |
