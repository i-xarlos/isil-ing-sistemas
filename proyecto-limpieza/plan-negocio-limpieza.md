# Plan de Negocio — Detergente Concentrado para Lavaplatos (Canadá)

**Ubicación:** St. Thomas, Ontario, Canada  
**Modelo:** E-commerce D2C (Direct-to-Consumer)  
**Producto:** Detergente seco concentrado para lavaplatos en dosis individuales  
**Fecha de creación:** 04/09/2026  

---

## 1. Resumen Ejecutivo

Negocio de venta directa de detergente concentrado para lavaplatos en formato de dosis individuales (sachets secos), enfocado en el mercado canadiense. El producto se diseña desde cero para optimizar logística: peso < 750g por paquete, volumen mínimo y alta recurrencia de compra.

**Propuesta de valor:** Detergente ecológico, concentrado, sin plástico, con envío económico a toda Canadá.

**Ventaja competitiva:** El formato seco eliminó el problema #1 de los productos de limpieza en e-commerce — enviar agua empaquetada.

## 7. Cadena de Suministro

### 7.1 Proveedor (Fabricante)

**Estrategia:** Buscar fabricante/contract packager en Ontario que provea:

```
Fabricante Ontario
  → Detergente
  → Sachets
  → Retail box
  → Starter Kit (opcional)
  → Producto terminado
```

**Ideal:** Un solo proveedor entregue todo el producto terminado. No queremos recibir 30,000 sachets sueltos + 1,000 cajas + ensamblar manualmente.

### 7.2 RFQ (Request for Quantity)

Carta de cotización para enviar a múltiples proveedores incluye:

- Detergente automático en polvo, dosis individuales 8–12 g
- 30 dosis por caja (inicial)
- Formulación private label
- Cantidades: 100, 250, 500, 1,000 cajas
- Packaging bilingüe (inglés/francés)
- Envío a St. Thomas, Ontario

**Preguntas clave al proveedor:**
1. ¿Cuál es el costo total puesto en St. Thomas?
2. ¿Cuál es el MOQ real para producto terminado con nuestro packaging?
3. ¿Cuánto costaría una muestra?
4. ¿Pueden producir sachet + caja, o necesitamos otro proveedor?
