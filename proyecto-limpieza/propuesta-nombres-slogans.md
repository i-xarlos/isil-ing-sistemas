# Propuesta de Nombres y Slogans

**Producto:** Detergente concentrado para lavaplatos en sachets individuales  
**Mercado:** Canadá  
**Posicionamiento:** Premium ecológico, fabricación canadiense, cero plástico  

---

## 1. Criterios de Selección

| Criterio | Por qué importa |
|---|---|
| **Fácil de recordar** | El cliente debe recordarlo después de verlo una vez |
| **Fácil de pronunciar** | Funciona en inglés y francés (mercado canadiense) |
| **Dominio disponible** | .ca o .com disponible para e-commerce |
| **Sin conflictos de marca** | No existe otra marca con el mismo nombre |
| **Comunica valor** | El nombre sugiere limpieza, ecología o concentración |
| **Escalable** | Funciona si expandimos a otros productos de limpieza |

## 6. Checklist para Elegir Nombre

Antes de decidir, verificar:

- [ ] Dominio .ca disponible
- [ ] Dominio .com disponible
- [ ] No existe marca registrada con ese nombre en Canadá (CIPO)
- [ ] No existe conflicto en redes sociales (Instagram, TikTok, Facebook)
- [ ] El nombre se pronuncia fácilmente en inglés Y francés
- [ ] El logo es viable (se puede diseñar algo limpio)
- [ ] El nombre funciona en un paquete pequeño (sachet)
- [ ] Suena bien cuando alguien lo dice en voz alta
- [ ] No tiene connotaciones negativas en otros idiomas

---

## 7. Proceso de Decisión

### Paso 1: Filtrar (de 8 a 3)

Elegir los 3 nombres que más resuenan con la visión del negocio.

### Paso 2: Verificar dominio

```bash
# Verificar disponibilidad
whois puredose.ca
whois sakclean.ca
whois cleanpod.ca
```

### Paso 3: Test de sonido

Decir el nombre en voz alta 10 veces. Si suena raro después de 5, descartarlo.

### Paso 4: Test de memoria

Decirle el nombre a 5 personas. Si 3 lo recuerdan al día siguiente, es bueno.

### Paso 5: Decidir

Elegir el nombre y registrarlo inmediatamente (dominio + redes sociales).
