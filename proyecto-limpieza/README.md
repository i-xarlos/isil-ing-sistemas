## Resumen Ejecutivo

### El Negocio

Venta directa de detergente concentrado para lavaplatos en sachets individuales. Producto diseñado desde cero para logística de e-commerce: peso < 750g, volumen mínimo, alta recurrencia.

### Por Qué Es Viable

| Factor | Dato clave |
|---|---|
| Inversión inicial | $1,800–$3,100 CAD |
| Margen bruto | ~70–75% |
| Margen neto (escenario medio) | 17% |
| Break-even | Mes 2–3 |
| Utilidad Año 1 (medio) | +$5,165 CAD |
| Formato único | Nadie ofrece sachets individuales en el estante |

### Datos Clave Verificados

| Dato | Fuente | Estado |
|---|---|---|
| Tarifas Chit Chats | chitchats.com | ✅ |
| Sendle Canadá | try.sendle.com | ⚠️ Halt enero 2026 |
| Precios competencia | Observación Walmart | ✅ |
| Self-storage St. Thomas | Make Space, Best Storage | ✅ |
| Regulación Canadá | Consumer Packaging Act | ✅ |
