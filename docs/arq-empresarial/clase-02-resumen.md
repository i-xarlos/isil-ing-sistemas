# Clase 2 Resumen

## Objetivos
- Analizar la importación y el valor de la Arquitectura Empresarial (AE).
- Entender los conceptos clave relacionados con AE.

## Conceptos Clave
- **Arquitectura Empresarial:** Estructura organizativa que define las interrelaciones de un negocio, información, aplicaciones y tecnología.
- **Negocio:** Elementos que definen lo que la organización hace.
- **Datos:** Información esencial para apoyar los procesos del negocio.
- **Aplicaciones:** Herramientas que facilitan las operaciones del negocio.
- **Tecnología:** Infraestructura técnica que soporta los datos y aplicaciones.
